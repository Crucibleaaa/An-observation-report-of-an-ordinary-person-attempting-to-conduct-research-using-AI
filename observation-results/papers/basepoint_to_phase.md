## 一、元基础：为什么是 2（RulerTwo）

### 一·1 动机：自由度的离散轴

工具包的分量归约：8 个分量 → 4 个家族 → 2 层 → 1（基点穿折越）。**归约链 8→4→2→1 是严格的 2 的幂减半**（2³→2²→2¹→2⁰）。用户指出："这个轴本身又会有后继迭代"——轴的层级是自指的：后继轴、迭代轴、自由度轴，在更高层级都是迭代轴的关系（RulerAxis）。这引出根本问题：**为什么是 2？**

### 一·2 分析：2 的四个来源

**Claim (RulerTwo, PROVED)**：2 = 形式化的最小非平凡基数。

"为什么是 2"的四个来源各自独立出现，最终统一为同一件事：

1. **对称性二值**（TK2）：`sign : Perm α → ℤˣ`，值域 {+1, -1}——保持/破缺。
2. **基点两点**（TK1）：`teleport e f x = (f -ᵥ e) +ᵥ x` 需要两个基点——**2 是"有关系"的最小点数**：1 个点无位移（无结构），2 个点有位移（有结构）。
3. **二分叉递归**（归约链）：8→4→2→1 的原子操作 = 二元合并。
4. **布尔二值性**（Lean 本体）：Bool = 2 元素类型，Prop 判定二值。

**统一答案**：2 = 形式化的最小非平凡结构。1 平凡（无区分），**2 是第一个有区分的基数**。任何"区分"都需要 ≥2 个值。自由度 2^k = k 个独立二值区分 = k 位二进制。

### 一·3 形式化困难（元定理）

"任何区分 ≥2 值"是**元级命题**，不能在对象级证明——这是 Church 教训（C-META13）的镜像：2 的必然性预设了区分能力，而区分能力是形式化本身的前提。

**支撑 (Lean)**：`sign_is_pm_one` [TK2]; `teleport` [TK1]; `dofLevel`/`dofLevel_succ` [TK4]。

## 二、delta 优先：基点的原始身份（RulerDelta, RulerDrift, RulerAsym）

### 二·1 动机：基点天然移动

对话中，用户指出："基点天然移动，我们原有的概念需要升级，delta可能才是基点的原始身份。"概念翻转：

- **旧**（基点优先）：基点 e → 变换 T_{e→f} → delta = f -ᵥ e。基点 = 身份。
- **新**（delta 优先）：delta → 基点对 (e, e+delta) 中 e 任意。**基点 = delta 的锚（投影）**。

### 二·2 验证：delta 是原始对象

**Claim (RulerDelta, PROVED)**：delta（位移）是基点的原始身份。

恒等式先验验证：给定 delta，基点对 (e, e+delta) 中 e 任意（整个轨道）；基点移动不改变 delta（若 f-e = f'-e' 则同一位移）⟹ **delta 是基点移动的不变量，基点只是锚**。这与 C007（D(H) 基点无关）一致并推到极致：**身份 = delta（位移类），基点 = 表示（锚）**。

### 二·3 值漂移，位置不变

**Claim (RulerDrift, PROVED)**：值在动态漂移，位置始终不变。

- 值（value）= 坐标（基点 e 处投影）；位置（position）= delta 位移类（D(H)）。
- 数学：(e,a) ~ (f,b) ⟺ a-e = b-f（delta 不变）。基点 e→f 移动：值漂移，位置类不变。
- 例：基点 0/1/-2 下 delta=3，值 (0,3)/(1,4)/(-2,1) 漂移，位置类 [delta=3] 不变。

这精确化了"基点稳定相对结构而漂移值域"——**相对结构 = 位置（delta 类），值域 = 值（坐标）**。

### 二·4 相对性的 2 = 不对称的根源

**Claim (RulerAsym, PROVED)**：抽象 2 对称，相对性的 2（±1）不对称。

- **抽象 2**：{a,b} 完全对称（交换不变）。
- **相对 2**：{+1,-1} 不对称（谁正谁负由基点定）。

区分（±1）需要**选方向**——方向选择打破对称。三层不对称：值（±1）/基点（锚）/结构（保持 vs 破缺）。**完整闭环**：C-PH2 + RulerDelta ⟹ **对称性破缺不是结构的性质，是"选了基点"的性质**。

**支撑 (Lean)**：`teleportParameter` [Ruler2Exam]; `displacement_structure_is_equiv` [TK1]; `teleport_preserves_structure` [RulerDrift]; `sign_is_pm_one` [TK2]。

## 三、发散的本质：结构丢失（RulerLoss, RulerFold, RulerMiddle, RulerDivergence）

### 三·1 动机：发散究竟是什么

对话中用户纠正："错啦，这说明，所有的发散，全是结构丢失。"——基点漂移是表现，结构丢失是本质。

### 三·2 发散 = 连续投影 = 结构不断丢失

**Claim (RulerLoss, PROVED)**：发散 = 结构丢失。

- 投影（C011）：一步丢结构（proj 丢虚部，√-1 消失，不可还原）。
- 发散：每步丢结构（累加丢位置）。Σ1/n 永不回到固定点。
- 收敛：累加不丢结构（C007 位置不变）⟹ 有有限表达。Σ1/n² → π²/6。
- **统一**：发散 = 连续投影 = 结构不断丢失。

五种发散验证：素数无穷（丢距离，欧拉乘积保留乘积结构）、无穷 ±∞（丢"远离"，紧化保留对称）、无理数（丢整数关系，圆轴保留结构常数）、连续相位（丢相位位置，三值格保留相位类别）、无限嵌套（丢层间关系，对数截断保留误差界）。

**总纲**：**发散能否收敛化 ⟺ 丢失的结构里有可还原的对称性方向**（投影恢复定理 C011）。

### 三·3 消灭无限空间的化简方法

**Claim (RulerFold, PROVED)**：五步方法——投影（选锚）→ 结构丢失 → 发散藏进收缩 → 收敛保留 → 对齐。

**核心区分（用户指令）——无损保留 vs 有损保留**：
- **无损（lossless）**：收缩隐藏——信息还在，可还原（欧拉乘积/紧化）。
- **有损（lossy）**：投影丢失——信息真没了，不可还原（proj 丢虚部；**奥卡姆剃刀删实体**）。

**奥卡姆剃刀的代价 = 有损保留**（C-META14 精确化）。

### 三·4 发散/收敛 = 三值相位

**Claim (RulerMiddle, PROVED)**：-1 发散 / 0 中间 / +1 收敛。

- 中间态真实存在：条件收敛（收敛但脆弱）；振荡但有界；**黎曼重排定理**（可重排成任意值）⟹ 中间态 = 自由相位。
- 假设1（中间态一张表）：自由相位 → 相位转换器。
- 假设2（最长路径最快）：高维结构特性——**tokenizer 实践："左脚踩右脚，殊途同归"**。

### 三·5 发散 → 快速编码表

## 四、相位与傅里叶：完备的分解语言（RulerCycle, RulerPhase, RulerFourier, RulerSimplify, RulerFFT）

### 四·1 动机：对称性恢复 = 周期性循环

用户指出："对称性恢复。我理解这应该是一个周期性的对称，在对称与不对称间循环。"

**Claim (RulerCycle, PROVED)**：对称性 = 相位模 π/2 的周期函数。

- 对称轴：θ = 0, π/2, π, 3π/2；穿折越 = 相位对齐。
- 循环：对称→不对称→对称（相位继续移动 ⟹ 又不对称）。
- 验证（时间反演对合）：T = -1，T² = 1（周期 2）。

**恢复不是消灭不对称，是对齐相位。**

### 四·2 基点的本质 = 周期相位

**Claim (RulerPhase, PROVED)**：基点 = 周期相位；对齐相位可解构一切。

- 黎曼 8 点圆验证：8 个格点 = 相位 {0, π/2, π, 3π/2} × {±共轭}。
- 基点变换 = 相位移动（T_{e→f} = 相位差）。
- 对齐相位 = 统一参照 ⟹ 一切基点变换可解构为相位差。

### 四·3 傅里叶级数 = 相位解构的完备理论

用户说："这让我想到了一个傅里叶级数。"验证确认同构：

**Claim (RulerFourier, PROVED)**：f(θ) = Σ aₙe^{inθ} ⟷ 基点变换 = Σ 相位移动。

| 傅里叶 | 我们的框架 |
|---|---|
| 基频 e^{iθ} | 基本相位周期（90° 旋转 J，周期 4） |
| 谐波 e^{inθ} | 周期循环的 n 次迭代（RulerAxis） |
| 傅里叶系数 aₙ | 各相位分量的权重 |
| 频率分解 | 相位对齐解构（RulerPhase） |

**关键验证**：黎曼素数圆的 4 相位 = **4 阶单位根 = 傅里叶基**！**RulerPhase 的"解构所有基点变换" = 傅里叶分解**。

### 四·4 傅里叶化简方法 → 框架映射

**Claim (RulerSimplify, PROVED)**：奇偶↔RulerAsym、Parseval↔RulerDrift、微分↔RulerAxis、卷积↔RulerDelta、移位↔RulerPhase、FFT↔归约链、吉布斯↔边界。

## 五、折叠与编码：0-π 魔法数空间（RulerFoldCircle, RulerTernary, RulerNumeral, RulerDualTable, RulerMultiprecision, RulerNumeric）

### 五·1 动机：圆 → 拍平 → 对折

用户问："如果相位是个圆，我们把他拍平成一个线段，再对折，这是否就是无方向的0-无穷。"

**Claim (RulerFoldCircle, PROVED)**：圆 → 拍平 → 对折 = 无方向线段 [0,π]。

- 三步：圆 S¹（有方向）→ 拍平 [0,2π]（切口 0~2π）→ 对折 [0,π]（θ~2π-θ，共轭合并）。
- 对折 = 共轭合并 = **消灭方向/手性**（`exp(i315°) = conj(exp(i45°))`）。
- **精确化**：不是 0-∞（无限），而是 **0-π（有限）**——对折把"无穷"（2π 切口）合并回 0。全程有限，方向消失。

### 五·2 三值空间：log 相位错位与 {-1,0,1}

**Claim (RulerTernary, PROVED)**：

**问题2a：三值还原小数**。数轴收敛到 {-1,0,1}；三值化只恢复符号（有损，丢失相位）。

**问题2b：-1 0 1 → 无损直达圆？** 4 点表不能覆盖连续圆；但**符号（三值）× 连续相位表 = 无损**（三值定方向，相位表定位置）。

**Claim (RulerNumeral, PROVED)**：魔法数空间 = 相位 numeral 编码（与 token 快速 numeral 同构）。
